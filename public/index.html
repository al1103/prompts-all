AI tạo prompt ảnh từ SRT

Đưa file phụ đề .srt vào. AI đọc hiểu lời thoại rồi tự chia cảnh, quyết mỗi cảnh cần mấy vật thể và viết mô tả hình ảnh cho từng vật. Ra tiền tố / hậu tố / danh sách dòng để dán vào tool tạo ảnh hàng loạt.

1 · File phụ đề

Kéo file .srt vào đây hoặc bấm để chọnChưa chọn file
Hoặc dán nội dung SRT

2 · Thiết lập và gọi AI

Nhịp nhanh nên 15–20 giây và 3–4 vật thể; lời chậm, trầm thì 25–35 giây. AI quyết số vật thể thực tế từng cảnh, từ 1 đến mức tối đa.
